# Image usage and evidence

`current/` are screenshot contact sheets uploaded by the owner of the current game. They are grounded **before** references.

`redesign_concepts/` are prior AI-generated conceptual mockups in this conversation, meant for broad style and composition; **they may invent gameplay data, player levels, currencies, rewards, names or UI interactions**. Do not copy values, protected symbols, or layout verbatim into the game.

All images are reference art, **not drop-in runtime game assets**, and not proofs of UI implementation. Use actual game screenshot verification.
